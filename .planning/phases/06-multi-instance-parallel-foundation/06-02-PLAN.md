## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| instances.conf → launcher spawn env | 運用者所有の設定ファイル。値が spawn 時の env として export される |
| launcher → PID/ログファイル (/tmp) | プロセス管理用の PID・ログを /tmp に書く |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03 | Tampering / Elevation | instances.conf 値のパース | mitigate | extra-env を `export KEY=VALUE` で適用し、conf 値を `eval` しない。コマンド注入面を作らない |
| T-06-04 | Information Disclosure | PID/ログファイル (/tmp/ht-webif-${PORT}.*) | mitigate | credential（CODEX_HOME 等）はパスのみで秘密値ではない。launcher は env 値をログに echo しない。loopback 単一ホスト前提（PROJECT.md §Constraints）で /tmp の既定権限を許容 |
| T-06-05 | Information Disclosure | up/status の curl 出力 | accept | /info は Plan 01 で最小フィールドに限定済み。credential を表示しない |
</threat_model>
