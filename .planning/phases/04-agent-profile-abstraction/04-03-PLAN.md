<objective>
Phase 4 検証で発見された 3 件のギャップを閉じる（CR-01 / CR-03 / WR-03）:

1. **CR-01（BLOCKER）**: `prompt_handler` が `output_covenant` 取得のために worker Mutex をロックするため、ターン実行中（最大 600 秒）は POST /prompt が即時応答できない回帰を解消する。プロファイルは起動後イミュータブルなので、`AppState` に `output_covenant` を直接持たせてロックフリーで読む。
2. **CR-03（WARNING）**: `model_flag` / `model_value` がパースされるだけで spawn コマンドに反映されない無言ノーオプを解消する。`AgentProfile::spawn_command()` で両方指定時にフラグと値を付与し、worker.rs の create_session 呼び出し 3 箇所で使う。
3. **WR-03（low priority）**: 参照ゼロの死蔵定数 `config::TURN_TIMEOUT` を削除し、将来の divergence 源を断つ。

Purpose: 非同期 POST /prompt の API 契約（turn_id 即返し）を v1.0 等価に回復し（PROF-03）、model 選択設定を実際に機能させる（PROF-05）。

Output: ロックフリーな covenant 取得、機能する model 選択、クリーンな config.rs。
</objective>
