新規 bash スクリプトを作成する（D-1/D-2/D-3）。`#!/usr/bin/env bash` + `set -euo pipefail`。コメント・ログ文字列は日本語、識別子は英語（CLAUDE.md Conventions）。完成後 `chmod +x scripts/ma-doctor.sh`。

read-only を厳守する（D-2）: スクリプト内で書き込み（>, >>, tee, mkdir, cp, rm, touch, sed -i 等）を一切行わない。ファイル/コマンドは存在確認・read パースのみ。

ヘルパー（launch-agents.sh の失敗集計方式を踏襲）:
- カウンタ変数 `OK_COUNT` / `WARN_COUNT` / `FAIL_COUNT`（SCREAMING_SNAKE_CASE、整数 0 初期化）。
- 出力関数 `ok()` / `warn()` / `fail()`: 第1引数にメッセージ、fail/warn は第2引数に修正ヒント（任意）。各関数は対応カウンタを `+1` し、`[OK]`/`[WARN]`/`[FAIL]` プレフィックス付きで1行出力する。FAIL/WARN にヒントがあれば次行にインデントして「ヒント: ...」を表示。
- 色付け: stdout が TTY のときだけ ANSI 色（OK=緑/WARN=黄/FAIL=赤）。`[[ -t 1 ]]` 判定。非 TTY はプレーン（色エスケープなし）。色定数は TTY 判定後に設定。
- 各チェックは個別失敗で abort しないよう明示分岐 / `|| true` を使う（`set -e` 下でも続行）。コマンド存在判定は `command -v <x> >/dev/null 2>&1` パターン。

JSON エンコーダ検出（launch-agents.sh の JSON_ENCODER / json_get_field 方式を自己完結で再現）:
- `JSON_ENCODER`: jq があれば "jq"、無く python3 があれば "python3"、両方無ければ ""（セクション 2 で FAIL 扱い、JSON 依存チェックは「確認不可」WARN にフォールバック）。
- `json_get_field <json> <field>`: jq は `jq -r ".${field} // empty"`、python3 は `python3 -c '...json.loads(...).get(...)...'`（launch-agents.sh:50-61 と同形）。

agents 探索順は src/config.rs load_agents_dir と一致させる（key_link）: 1) `AGENTS_DIR` env（非空なら最優先・存在チェックなし）, 2) `$(pwd)/agents` が dir なら採用, 3) `${XDG_CONFIG_HOME:-$HOME/.config}/claude-p/agents` が dir なら採用。空文字 XDG_CONFIG_HOME は未設定扱い。

usage（`--help`/`-h`）: スクリプト概要・実行例・「report-only（書き込みなし）」「FAIL があれば exit 1」を明記。dispatch は引数なし＝診断実行、`-h|--help`＝usage、それ以外の引数＝usage + exit 1。

診断セクション（順に実行し、見出しを echo してから各チェック）:

セクション1 インストール/PATH:

- `$HOME/.local/bin` が `$PATH` に含まれるか（`case ":$PATH:" in *":$HOME/.local/bin:"*)` 判定）。含まれれば ok、無ければ warn（ヒント: export PATH="$HOME/.local/bin:$PATH" を ~/.bashrc 等に追加）。

セクション2 依存コマンド:
- `ht-mcp`（command -v、無ければ fail）、`curl`（無ければ fail）。
- `jq` または `python3` のいずれか: どちらか1つでも有れば ok（採用エンコーダ名を表示）、両方無ければ fail（ヒント: jq か python3 をインストール）。

セクション3 agents プロファイル解決:
- 上記 3 段 precedence で有効 dir を判定。どれも無ければ fail（ヒント: AGENTS_DIR を設定 or ./agents を配置 or just install で XDG global に配置）し、以降の TOML 列挙はスキップ。
- 採用 dir と採用根拠（AGENTS_DIR / cwd/agents / XDG global）を ok で表示。
- 採用 dir の `*.toml` を列挙（無ければ warn）。各 TOML から `command`（無ければ `cmd`）配列の先頭要素を抽出: python3 tomllib が使えれば優先（`python3 -c 'import tomllib,sys; d=tomllib.load(open(sys.argv[1],"rb")); a=d.get("command") or d.get("cmd") or []; print(a[0] if a else "")'`）、無ければ簡易 grep（`command`/`cmd` 行の最初のクォート文字列を抽出）。抽出した「プロファイル名 → command[0]」を後続セクション4/5 で再利用するため配列/連想配列に保持。

セクション7 instances.conf（cwd）:
- `$(pwd)/instances.conf` 存在しなければ warn（ヒント: 多重起動する場合は instances.conf を配置。単一インスタンスなら不要）してセクション終了。
- あれば各行を launch-agents.sh と同じ規則でパース（`# 始まり`/空行スキップ、`read -ra fields`、fields[0]=agent fields[1]=port）。各 agent/port について: port が `^[0-9]+$` でなければ fail。port 重複があれば fail（既出 port を集合で追跡）。agent がセクション3 のプロファイル一覧で解決可能かを確認、解決不可なら warn。問題なければ各行 ok（agent/port 表示）。後続セクション8 用に (agent,port) ペアを保持。
