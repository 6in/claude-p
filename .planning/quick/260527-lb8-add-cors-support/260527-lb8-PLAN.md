<objective>
ht-webif HTTP API に CORS サポートを追加する。既定はフルパーミッシブ（`*`、全オリジン許可）で、
`CORS_ORIGINS` 環境変数（カンマ区切り）で絞り込めるようにする。tower-http の `CorsLayer` を
axum Router にレイヤーとして被せる方式で、ルートやハンドラのシグネチャは一切変更しない。

Purpose:
- Web フロントエンドから直接 ht-webif を叩けるようにする（curl 以外の利用シナリオを開く）
- `.allow_credentials(true)` は意図的に付けない — Cookie/認証情報を扱わない API なので不要、
  かつ `*` + credentials は CORS 仕様で同時指定不可（ブラウザが拒否する）
- 環境変数の優先順位は他の設定（PORT, TURNS_DIR）と揃える: 実環境変数 > .env > 既定値

Output:
- `tower-http = { version = "0.6", features = ["cors"] }` が依存に追加され `cargo build --release` が通る
- `load_cors_origins()` が config.rs に追加される（純粋関数、env 経由でリスト取得）
- `build_router` が `CorsLayer` を被せた Router を返す（既定 Any、env 指定時は明示オリジン）
- 11 個の既存テストが green を保ち、CORS 検証用の新規テスト 2 件（preflight + actual request）が追加される
- `.env.example` と `README.md` に CORS 設定の使い方が記載される
</objective>

<design_notes>
**build_router のシグネチャをどう拡張するか:**
このプランでは `build_router(state, cors_origins: Vec<String>)` の **追加引数方式** を採用する。
理由:
- `AppState` は「リクエストごとに参照するランタイム状態」を持つコンテナで、CORS は起動時に
  1 回だけ Router に焼き込まれる構成情報なので、AppState に押し込むより別引数の方が責任分離が綺麗
- 既存テスト 11 件のヘルパ `build_test_state` は AppState を作るだけで build_router は呼ばないので、
  AppState のフィールドを増やすと全テストのヘルパに影響する。引数方式なら test 側で `build_router(state, vec!["*".to_string()])` を渡すだけで済む
- main.rs の呼び出しも `build_router(state, cors_origins)` の 1 行差分で済む
</design_notes>

**2. webif/src/config.rs に `load_cors_origins() -> Vec<String>` を追加する。**
位置は既存 `load_turns_dir` の直後。実装は以下のとおり（純粋関数、env 経由でリスト取得）:

```
pub fn load_cors_origins() -> Vec<String>
```

- 環境変数 `CORS_ORIGINS` が設定されていればカンマで split、各要素を trim、空文字列要素は除外
- 未設定なら `vec!["*".to_string()]` を返す（フルパーミッシブ）
- `///` doc comment（日本語）で 「カンマ区切りリスト、または `*` でワイルドカード。未設定なら既定値 `vec!["*"]` (フルパーミッシブ)。優先順位: 実環境変数 CORS_ORIGINS > .env の値 > 既定値」 を明記
- 他の load_* 関数と同じ形式（pub fn、`std::env::var` 経由）

**3. webif/src/http.rs の `build_router` を `(state, cors_origins: Vec<String>) -> Router` に拡張する。**
シグネチャ:
```
pub fn build_router<M: Mcp + Restartable + Send + 'static>(
    state: Arc<AppState<M>>,
    cors_origins: Vec<String>,
) -> Router
```

CorsLayer の組み立てロジック（関数内で構築）:
- `cors_origins` に `*` がいずれかの要素として含まれる場合: `CorsLayer::new().allow_origin(Any).allow_methods([Method::GET, Method::POST, Method::OPTIONS]).allow_headers([header::CONTENT_TYPE])`
- それ以外: 各オリジン文字列を `HeaderValue::from_str` で変換、失敗したものは `filter_map` で除外し、`allow_origin(Vec<HeaderValue>)` に渡す。methods/headers は同上
- **`.allow_credentials(true)` は付けない**（CORS 仕様で `*` + credentials は同時不可、かつ API に Cookie/auth なし）
- Router の組み立て末尾で `.layer(cors)` を `.with_state(state)` の **前** に挟む（axum 0.8 のレイヤー順序: route -> layer -> state）

必要な `use` を file 冒頭の use 群に追加:
- `use axum::http::{header, HeaderValue, Method};`（既存の StatusCode 行をマージしても良い）
- `use tower_http::cors::{Any, CorsLayer};`

build_router の `///` doc comment（日本語）を更新: 「CORS_ORIGINS で絞り込み可、既定は全許可 (`*`)」を 1 行追記。
