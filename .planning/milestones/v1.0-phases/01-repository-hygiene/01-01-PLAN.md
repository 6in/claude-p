<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 開発者ローカル → Git リモート（GitHub 等） | コミット内容がリポジトリホスティングサービスへ push される境界 |
| 開発者ローカル → CI（v2 で導入予定） | ワーキングツリーが CI ランナーへ転送される境界 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | I (情報開示) | `.env`（OAuth/環境変数など秘密情報を含む可能性） | mitigate | `.gitignore` で `/.env`、`.env.local` を除外。`.env.example` は ignore しないテンプレートとして残す（acceptance: `git check-ignore .env` exit 0、`git check-ignore .env.example` exit 1） |
| T-01-02 | I (情報開示) | `turns/`（HT-PROTOCOL の prompt/result/status ファイル — 実行履歴・LLM 入出力が残る） | mitigate | `.gitignore` で `/turns/` を除外。実行のたびに増えるユーザ会話ログをコミットから締め出す |
| T-01-03 | T (改ざん) | `.idea/`、`.vscode/` の自動生成設定 | accept | IDE 設定はチーム間で差異が出ることが期待される。誤コミットによる強制適用が問題化したことは過去にあるが low risk、ignore で十分 |
| T-01-04 | D (DoS — リポジトリ肥大化) | `target/`（数百 MB の Rust ビルド成果物） | mitigate | `.gitignore` で `/target/` と `webif/target/` を除外。push のたびに数十〜数百 MB を転送する事態を防ぐ |
| T-01-05 | I (情報開示) | `~/.claude/.credentials.json`（CLAUDE.md で言及される OAuth credentials） | accept | このファイルはユーザのホームディレクトリ配下にあり、本リポジトリのワーキングツリー外。リポジトリ側 `.gitignore` の対象外（境界の外側） |
</threat_model>
